# Short present-tense title naming the decision

- Status: Proposed | Accepted | Superseded by ADR-NNNN
- Date: YYYY-MM-DD
- Deciders: who made the call

## Context

What forced the decision. The constraint, the observation in the data, or the
standard's control, stated concretely enough that a reader can tell whether it
still holds. Name the alternative that was actually tempting.

## Decision

What was decided, in the present tense, as a rule someone could apply. Point at
the code or the document that implements it.

## Consequences

What follows, including what this makes harder or worse. A record with only
upsides has not finished thinking. Name the observation that would make this
record worth superseding.
